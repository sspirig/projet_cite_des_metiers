# Projet Chatbot et Visite virtuelle

Pour utiliser ce projet il faudra juste prendre le script de base de données et le mettre sur votre serveur.

Deuxiemement vu qu'il n'y a pas d'utilisateur crée dans le script il vous faudra prendre vos identifiants de base de données et les inscrire dans le fichier db.php qui se trouve dans le dossier php.

Ensuite vous n'aurez qu'à essayer le site en cliquant soit sur le bouton Chatbot ou encore Visite.
